# MovieVerse - Movie Review Website

MovieVerse is a simple multi-page movie review website built using only HTML and CSS.

The project contains 6 different pages with separate CSS files for each page.

---

## Features

- Responsive multi-page design
- Clean and modern UI
- Separate CSS file for every HTML page
- Movie cards and review sections
- Contact form page
- Simple navigation bar

---

## Technologies Used

- HTML5
- CSS3

---

## Pages Included

| Page | Description |
|------|-------------|
| Home | Landing page with hero section |
| Movies | Movie collection page |
| Reviews | User reviews page |
| Top Rated | Best rated movies |
| About | Information about the website |
| Contact | Contact form page |
